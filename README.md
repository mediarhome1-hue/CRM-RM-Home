# CRM RM Home

Projeto e sistema CRM RM Home desenvolvido com Next.js, React, TailwindCSS e Supabase.

## Scripts Disponíveis

- `npm run dev`: Inicia o servidor local de desenvolvimento.
- `npm run build`: Cria o build de produção otimizado para deploy.
- `npm run start`: Executa o build de produção localmente.
- `npm run lint`: Executa a verificação de linting do código.

## Deploy

Este repositório está integrado para deploy contínuo na Vercel a cada push na branch `main`.
